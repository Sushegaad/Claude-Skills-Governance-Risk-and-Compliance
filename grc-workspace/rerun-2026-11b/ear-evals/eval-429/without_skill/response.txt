Preliminary classifications. All of these need a check against the actual specifications, and the cryptography ones depend on the specific functions.

1. 5G base station. Commercial cellular base stations are Category 5 Part 1 (telecommunications). If the product has no cryptography beyond what is described in the telecommunications entries, it is generally 5A991 (for example 5A991.b). With encryption of the "information security" type, it falls under 5A002 (ENC). Many base stations use only standard air-interface encryption, which is excluded from 5A002 under Note 2 to 5A002.a, but with additional cryptography (for example IPsec or MACsec backhaul security), it can be 5A002.a. If it is network infrastructure, it is generally authorized under 740.17(b)(2) (classification request needed), rather than being mass market. Without any controlled cryptography, 5A991 (NS2, AT1, with Anti-terrorism controls) is the likely answer. Also check for 5A001 features, such as certain jamming, intercept or high-performance features.

2. VPN encryption appliance. This is network infrastructure with cryptography for data confidentiality, with a key length above 56 bits symmetric. It is 5A002.a (ENC, NS1, AT1). It is not eligible for mass-market treatment because of its infrastructure nature. It is authorized under License Exception ENC 740.17(b)(2) or (b)(3) as applicable, which requires a classification request to BIS, and it needs semi-annual or annual sales reporting for the (b)(2)/(b)(3) path. Note that it is not 5A992.c, since mass market does not apply to it.

3. Mass-market disk-encryption software. This is 5D992.c (the mass-market designation) after self-classification or review under 740.17(b)(1) or mass-market note 3 to Category 5 Part 2. It is controlled for AT only, with no NS reason, and is eligible for NLR to most destinations. Mass-market status requires that it be sold to the general public, easy to install without supplier assistance, and not highly customised. If it fails these criteria, it is 5D002.c.1 (ENC) instead. Cryptographic functionality over 56 bits means it is not EAR99. Self-classification reporting under 742.15(b) is required annually. Note that if it is on the list under 740.17(b)(1), a classification request is not required.
