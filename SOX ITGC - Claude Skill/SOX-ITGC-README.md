# SOX ITGC — Claude Skill

**File:** `sox-itgc.skill`

Turns Claude into an expert **SOX IT General Controls practitioner** for finance, internal audit and IT compliance teams — the deadline-driven, quarterly discipline behind every ICFR programme.

## What it covers
- The **four ITGC domains** external auditors test for SOX 404: access to programs and data, program changes, computer operations, program development — with the standard control set, test procedures and evidence expectations
- **Scoping** in-scope systems top-down from the financial statements (AS 2201/GAIT logic), SOC 1 reliance and CUEC mapping, IPE and end-user computing
- **Risk-and-control matrices**, workpaper-ready **control narratives and test scripts** (sample-size conventions labelled as convention, not regulation)
- **Deficiency evaluation** — the control deficiency → significant deficiency → material weakness ladder per AS 2201 Appendix A and Reg S-X 1-02(a)(4), with aggregation logic and ITGC-specific evaluation through dependent application controls
- **404(a)/404(b) applicability**: filer thresholds, EGC exemptions, IPO timelines (first 404(a) in the second 10-K) — including the flag on the SEC's pending May 2026 filer-framework proposal
- Current context: COSO 2013 (still operative), PCAOB 2025 inspection priorities, GenAI in financial systems as an emerging ITGC topic

## What it does
Scoping memos · RCMs · narratives and test scripts · deficiency ladder walkthroughs with citations · remediation plans timed for re-testing before year-end.

**Trigger phrases:** `SOX`, `ITGC`, `ICFR`, `404(b)`, `material weakness`, `user access review`, `segregation of duties`, `change management controls`, `SOX testing`, `PCAOB audit`
