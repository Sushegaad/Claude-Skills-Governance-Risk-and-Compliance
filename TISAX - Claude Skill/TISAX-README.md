# TISAX — Claude Skill

**File:** `tisax.skill`

Turns Claude into an expert **TISAX (Trusted Information Security Assessment Exchange)** advisor for the automotive supply chain — the ENX/VDA assessment regime that OEMs (VW, BMW, Mercedes-Benz, Audi) require from suppliers and service providers.

## What it covers
- **VDA ISA 6** (current through 2026: 46 IS controls, 22 prototype controls, 4 data-protection controls, must/should tiers) and the **ISA2027 transition** (published July 1, 2026; mandatory for assessments ordered from January 1, 2027)
- **Assessment levels AL1/AL2/AL3** and all **12 objectives/labels** — including the ISA-6 renaming (Confidential / Strictly Confidential + availability labels replacing Info High/Very High)
- **Maturity scoring** (0–5, target 3, cutback rules), the **ENX portal process** (fees, standard scoping, audit-provider selection), corrective action plans with the **9-month window**, temporary labels, and **3-year validity**
- **ISO 27001:2022 mapping** (~70–80% overlap) with the automotive-specific deltas that certification alone doesn't cover

## What it does
Gap assessments in maturity terms · label/objective selection walk-throughs · readiness roadmaps sequenced must → should → additional requirements · audit-prep evidence checklists · the 2026/27 order-date decision.

**Trigger phrases:** `TISAX`, `VDA ISA`, `ENX`, `TISAX label`, `AL2 assessment`, `AL3 assessment`, `prototype protection`, `automotive supplier security`, `ISA2027`, `TISAX vs ISO 27001`
