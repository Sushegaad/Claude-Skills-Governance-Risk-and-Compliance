# Cyber Essentials — Claude Skill

**File:** `cyber-essentials.skill`

Turns Claude into an expert adviser for **UK Cyber Essentials and Cyber Essentials Plus** — the NCSC-owned, IASME-delivered baseline certification that UK government contracts (PPN 014), the MoD supply chain and growing private-sector supply chains require.

## What it covers
- The **current Danzell question set** (Requirements for IT Infrastructure v3.3 — mandatory for assessment accounts from April 27, 2026) and the Willow transition window, including the two new **automatic-fail** conditions (missing cloud MFA; the 14-day update questions)
- The **five control themes** — firewalls, secure configuration, security update management, user access control, malware protection — with the details assessors mark against
- **Scoping**: cloud services (never excludable), BYOD, home and remote working, sub-set segregation, the **14-day critical/high (CVSS ≥7) patch rule**, unsupported-software handling
- **Certification mechanics**: pricing (£320–£600 +VAT by size), CE+ technical audits within 3 months (device sampling, scans, malware/email/browser tests), annual renewal, the bundled **£25k cyber liability insurance** (<£20m turnover)
- **Procurement mandates**: PPN 014, MoD Defence Cyber Certification (Level 0 by Dec 31, 2026), NHS DSPT interplay

## What it does
Readiness gap assessments with auto-fail flags · scope statements · question-set walkthroughs with assessor-ready wording · CE+ audit-day preparation · procurement compliance timelines back-planned from bid dates.

**Trigger phrases:** `Cyber Essentials`, `Cyber Essentials Plus`, `CE+`, `IASME`, `Danzell`, `NCSC certification`, `PPN 014`, `MoD supply chain`, `UK government contract security`
